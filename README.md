## ✨ قابلیت‌های کامل پروژه

### 1️⃣ **حسابداری عمومی و دفتر کل**
- ✅ **صدور سند حسابداری (وُچر)**: امکان ثبت اسناد حسابداری با چندین سطر بدهکار و بستانکار
- ✅ **تراز آزمایشی**: گزارش تراز آزمایشی دو ستونه و چهار ستونه برای کنترل توازن حساب‌ها
- ✅ **دفتر روزنامه**: نمایش کلیه عملیات مالی به ترتیب تاریخ
- ✅ **دفتر معین**: گزارش تفصیلی هر حساب با تمام ریزعملیات
- ✅ **کدینگ حساب‌ها**: پشتیبانی از حساب‌های کل، معین و تفصیلی
- ✅ **اسناد خودکار**: تولید خودکار سند حسابداری هنگام ثبت خرید، فروش، دریافت و پرداخت

### 2️⃣ **مدیریت حساب‌ها**
- ✅ **تعریف حساب‌های کل**: ایجاد حساب‌های اصلی دفتر کل
- ✅ **تعریف حساب‌های معین**: حساب‌های زیرمجموعه هر حساب کل
- ✅ **تعریف حساب‌های تفصیلی**: طرف حساب‌های شخصی و حقوقی
- ✅ **درختواره حساب‌ها**: نمایش سلسله مراتبی حساب‌ها
- ✅ **جستجوی پیشرفته**: امکان جستجو در بین تمام حساب‌ها

### 3️⃣ **خزانه‌داری و نقدینگی**
- ✅ **صندوق‌ها (Cashboxes)**: تعریف صندوق‌های مختلف ریالی و ارزی
- ✅ **بانک‌ها**: مدیریت حساب‌های بانکی با شماره شباه و موجودی
- ✅ **تنخواه‌گردان‌ها (Petty Cash)**: مدیریت تنخواه‌های شرکت و پرسنل
- ✅ **انتقال وجه**: جابجایی پول بین صندوق، بانک و تنخواه
- ✅ **گزارش موجودی**: مشاهده لحظه‌ای موجودی تمام صندوق‌ها و بانک‌ها

- ✅ **ثبت چک‌های پرداختنی**: چک‌هایی که به suppliers داده شده

## 📥 نحوه نصب و راه‌اندازی

### مرحله 1: دانلود پروژه

**دانلود فایل مخصوص cPanel:**
فایل `accounting_system_v01_beta_cpanel.tar.gz` را دانلود کنید. این فایل شامل `index.php` است که مستقیماً در هاست cPanel قابل استفاده می‌باشد.

**دانلود فایل کامل پروژه:**
فایل `accounting_system_v01_beta.tar.gz` را دانلود کنید که شامل تمام فایل‌های پروژه به همراه مستندات است.

### مرحله 2: استخراج فایل

**برای نصب در cPanel:**
1. وارد File Manager هاست cPanel خود شوید
2. به پوشه `public_html` بروید (یا پوشه‌ای که می‌خواهید پروژه در آن نصب شود)
3. روی دکمه Upload کلیک کرده و فایل `accounting_system_v01_beta_cpanel.tar.gz` را آپلود کنید
4. پس از آپلود، روی فایل کلیک راست کرده و Extract را بزنید
5. فایل `index.php` استخراج خواهد شد

**برای نصب در سرور لینوکس:**
```bash
tar -xzf accounting_system_v01_beta.tar.gz
```
یا در ویندوز با نرم‌افزار WinRAR یا 7-Zip فایل را استخراج کنید.

### مرحله 3: انتقال به وب‌سرور

**اگر از cPanel استفاده می‌کنید:** این مرحله خودکار در مرحله قبل انجام شده است. فایل `index.php` هم‌اکنون در پوشه `public_html` قرار دارد.

**برای سایر وب‌سرورها:**
فایل `index.php` را به پوشه root وب‌سرور خود منتقل کنید:
- **Apache**: `/var/www/html/` یا `htdocs/`
- **Nginx**: `/usr/share/nginx/html/`
- **XAMPP**: `C:/xampp/htdocs/`
- **WAMP**: `C:/wamp64/www/`

### مرحله 4: تنظیم دسترسی‌ها

**برای cPanel:**
1. در File Manager، روی پوشه `data` کلیک راست کنید (اگر وجود ندارد، صبر کنید تا در مرحله نصب ساخته شود)
2. گزینه Change Permissions را انتخاب کنید
3. تیک‌های Read, Write, Execute را برای Owner, Group, Public فعال کنید (یا عدد 777 را وارد کنید)
4. روی Save Changes کلیک کنید

**برای سرور لینوکس:**
```bash
chmod -R 777 /path/to/data/
```
این دستور پوشه `data` را می‌سازد و دسترسی نوشتن می‌دهد.

### مرحله 5: اجرای نصب‌کننده

**برای cPanel:**
مرورگر را باز کرده و به آدرس زیر بروید:
```
https://yourdomain.com/index.php
```
یا اگر در ساب‌دامین نصب کرده‌اید:
```
https://subdomain.yourdomain.com/index.php
```

**برای لوکال هاست (XAMPP/WAMP):**
```
http://localhost/index.php
```

### مرحله 6: تکمیل نصب
به صورت خودکار به صفحه نصب هدایت می‌شوید. روی دکمه **"نصب سیستم"** کلیک کنید تا:
- پوشه `data/` ساخته شود
- فایل‌های JSON اولیه ایجاد شوند
- حساب‌های پیش‌فرض تنظیم شوند
- تنظیمات اولیه اعمال شوند

## 🔧 عیب‌یابی و مشکلات رایج

### مشکل: پوشه data ساخته نمی‌شود
**راه حل**: دسترسی پوشه والد را بررسی کنید:
```bash
chmod 755 /path/to/parent/folder
```

### مشکل: داده‌ها ذخیره نمی‌شوند
**راه حل**: دسترسی پوشه data را بررسی کنید:
```bash
chmod -R 777 data/
```

### مشکل: تاریخ‌ها به درستی نمایش داده نمی‌شوند
**راه حل**: مطمئن شوید timezone تنظیم شده است:
```php
date_default_timezone_set('Asia/Tehran');
```

### مشکل: فایل بکاپ دانلود نمی‌شود
**راه حل**: محدودیت‌های مرورگر و firewall را بررسی کنید
