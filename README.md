# سیستم حسابداری جامع - نسخه 01 بتا

## درباره پروژه

این یک سیستم حسابداری جامع و کامل است که با زبان PHP توسعه داده شده و برای کسب‌وکارهای کوچک و متوسط طراحی شده است. سیستم بدون نیاز به پایگاه داده SQL و با استفاده از فایل‌های JSON کار می‌کند که نصب و راه‌اندازی آن را بسیار ساده می‌کند.

### ویژگی‌های اصلی:

- **حسابداری دوطرفه**: ثبت اسناد حسابداری با رعایت اصل دوطرفه بودن
- **مدیریت حساب‌ها**: درختواره حساب‌ها با سطوح مختلف (کل، معین، تفصیلی)
- **مدیریت اشخاص**: ثبت مشتریان و تأمین‌کنندگان
- **مدیریت چک‌ها**: ثبت و پیگیری چک‌های دریافتنی و پرداختنی
- **خزانه‌داری**: مدیریت صندوق‌ها، بانک‌ها و تنخواه‌گردان‌ها
- **دوره‌های مالی**: تعریف دوره‌های مالی مختلف
- **خرید و فروش**: ثبت فاکتورهای خرید و فروش
- **انبارداری**: مدیریت موجودی کالا
- **گزارش‌گیری**: گزارش‌های متنوع حسابداری
- **تقویم شمسی**: پشتیبانی کامل از تاریخ شمسی

## نحوه نصب

### پیش‌نیازها:
- سرور وب با پشتیبانی از PHP 7.4 یا بالاتر
- فعال بودن افزونه‌های JSON و Session در PHP
- دسترسی نوشتن به پوشه پروژه

### مراحل نصب:

1. **دانلود فایل پروژه**
   - فایل `accounting_system_v01_beta.tar.gz` را دانلود کنید

2. **استخراج فایل‌ها**
   ```bash
   tar -xzf accounting_system_v01_beta.tar.gz
   ```

3. **انتقال به پوشه وب‌سرور**
   - فایل‌ها را به پوشه public_html یا htdocs منتقل کنید

4. **تنظیم دسترسی‌ها**
   ```bash
   chmod -R 755 /path/to/project
   chmod -R 777 /path/to/project/data
   ```

5. **راه‌اندازی اولیه**
   - مرورگر را باز کرده و به آدرس پروژه بروید
   - سیستم به صورت خودکار شما را به صفحه نصب هدایت می‌کند
   - روی دکمه "نصب" کلیک کنید تا عملیات نصب انجام شود

6. **شروع به کار**
   - پس از نصب موفق، به داشبورد سیستم هدایت می‌شوید
   - می‌توانید عملیات حسابداری خود را شروع کنید

## ساختار فایل‌های داده

سیستم از فایل‌های JSON زیر برای ذخیره اطلاعات استفاده می‌کند:
- `accounts.json`: حساب‌های حسابداری
- `vouchers.json`: اسناد حسابداری
- `transactions.json`: تراکنش‌های مالی
- `customers.json`: مشتریان
- `suppliers.json`: تأمین‌کنندگان
- `checks.json`: چک‌ها
- `cashboxes.json`: صندوق‌ها
- `banks.json`: بانک‌ها
- `petty_cash.json`: تنخواه‌ها
- `periods.json`: دوره‌های مالی
- `inventory.json`: موجودی انبار
- `purchases.json`: فاکتورهای خرید
- `sales.json`: فاکتورهای فروش
- `settings.json`: تنظیمات سیستم
